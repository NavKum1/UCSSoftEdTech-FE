Every piece of work handed in for a coding challenge or a work trial gets an evidence pack. It brings together what you need to decide fairly. Edulexa doesn't advance or turn down anyone: a reviewer records every decision, with a rationale.

## Find the work

Open [ui: Evidence packs] under [ui: Review]. The [ui: Evidence review queue] shows the work [ui: Awaiting decision] first. You can narrow it by [ui: Challenge], by [ui: Integrity signals] or by [ui: Decision]. Select a candidate's name to open their pack.

## What's in the pack

- **At the top:** the task, its [ui: AI policy], when the work was handed in, how long the candidate spent editing, and the [ui: Evidence version].
- [ui: The code compared with the explanation]: whether the code and the defense tell the same story. For example, the code passes most tests but the candidate struggled to explain it.
- **Tests:** which tests passed. For a work trial, [ui: Planted defects] shows which bugs the candidate fixed.
- [ui: Code changes]: what the candidate changed, file by file.
- [ui: AI assistant usage]: when AI was allowed, each question the candidate asked and how much of the final code came from the assistant.
- [ui: Integrity signals]: patterns worth talking about, such as code pasted from outside the editor, or code much like another candidate's. Each one says how much it adds to the signal score. Many have innocent explanations.
- [ui: Defense (voice or written)]: the score, the recording, and the questions and answers.
- [ui: Approved accommodations] and [ui: Candidate appeals], if there are any.
- [ui: Decision history]: every decision recorded so far.

The pack never includes voice sentiment or emotion analysis. Demographic data is only used in combined bias audit figures.

## Record your decision

1. Under [ui: Record your decision], choose [ui: Advance], [ui: Hold] or [ui: Decline].
2. In [ui: Rationale (shared with your team and connected ATS)], write what in the evidence supports your decision. It needs at least 20 characters.
3. Select [ui: Submit decision].

If the evidence changed after you opened the pack, for example because the defense just finished, Edulexa asks you to look again. Select [ui: Reload evidence], review it, and decide. An earlier decision stays in the history, marked [ui: Evidence has changed since this decision].

To keep a copy, select [ui: Print / Save as PDF]. Candidates can appeal your decision.
