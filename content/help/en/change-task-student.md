Some coding assessments ask you to make one small change to your own code before the viva. It shows you know your code well enough to change it.

1. After you hand in your work, the change task is prepared from your own code. This usually takes a minute or two; the page updates by itself.
2. When it's ready, the page shows how many minutes you'll have. You see what to change only when you start, and the clock runs from then. Select [ui: Start the change task (20 minutes)] (your time may differ).
3. Select [ui: Open the workspace (new tab)]. You work on a copy of your code, with the AI assistant off.
4. Make the change, run the tests, and submit in the workspace. Then come back and select [ui: Hand in the change].

If time runs out before you hand in, whatever you submitted last in the workspace counts. Then the viva comes next: see [Do the viva](/help/the-viva).

> Once your change task has started, the work you handed in can't be replaced.
